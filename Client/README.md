# Client

Ce périmètre contient les parcours d'achat et de consultation : catalogue,
catégories, fiche commerçant, favoris, panier, destinataire, récapitulatif et
confirmation. La nouvelle entrée d'interface est `../boutique-client.html`.

Les ressources partagées restent provisoirement dans `../assets/`, car elles
sont aussi chargées par les pages Wix existantes. Les déplacer sans changer les
routages Wix casserait les URL publiques; la migration doit être effectuée dans
le projet Wix source au même moment que la publication.
